# KoyoFes NFC Write

高専祭のスタンプラリー用URLを、NFCタグへ書き込むためのシンプルなWebページです。

## 使い方

1. Android端末のChromeでページを開きます。
2. 書き込みたい展示・団体の「書き込む」ボタンを押します。
3. 「カードをタッチ...」と表示されたら、NFCタグを端末にかざします。
4. 「完了！」と表示されたら書き込み完了です。

## 対応環境

- Web NFCに対応したAndroid端末
- NFCを有効にしたGoogle Chrome
- 書き込み可能なNFCタグ

Web NFCはiPhoneや、Web NFCに対応していないブラウザでは利用できません。

## 開発・公開

このプロジェクトは、依存関係のない静的なHTMLページです。`index.html`をWebサーバーまたはGitHub Pagesで公開して利用できます。

展示・団体の追加やURLの変更は、`index.html`内の`data`配列を編集してください。

## 注意

- NFCタグへの書き込み時は、既存の内容が上書きされます。
- 書き込み対象のURLには、スタンプラリーの認証用トークンが含まれます。URLを不用意に共有しないでください。
